# Job Person — лендинг

Статический сайт по макету из `figcraft/landing.figcraft` (5 экранов, 1440 px).
Сборка не нужна: HTML, CSS, немного JS и локальные шрифты.

## Структура

```
site/
├── index.html              весь лендинг: первый экран, услуги, шаги, цены, контакты
├── 404.html                страница для несуществующих адресов
├── robots.txt
├── sitemap.xml
├── .htaccess               сжатие, кэш, защита служебных файлов (Apache/Beget)
├── php/
│   └── send.php            обработчик формы заявки
└── assets/
    ├── css/style.css       токены, компоненты, адаптив
    ├── css/fonts.css       @font-face для локальных шрифтов
    ├── js/main.js          меню, появление блоков, валидация формы
    ├── fonts/              Montserrat + Inter (variable woff2, cyrillic + latin)
    └── img/                logo.png, hero.jpg, favicon.png, apple-touch-icon.png
```

## Запуск на localhost

Из папки `site`:

```bash
python -m http.server 8000
```

Откройте <http://localhost:8000>. Подойдёт любой статический сервер:
`npx serve .`, `php -S localhost:8000`, VS Code Live Server.

## Деплой на Beget

1. Панель Beget → **Файловый менеджер** (или FTP/SFTP-клиент) → папка `public_html`
   вашего домена.
2. Загрузите **содержимое** папки `site/` (не саму папку): `index.html`,
   `404.html`, `assets/`, `php/`, `.htaccess`, `robots.txt`, `sitemap.xml`.
3. Убедитесь, что `.htaccess` тоже скопирован — в файловом менеджере включите показ
   скрытых файлов, он влияет на сжатие, кэш и 404.
4. Проверьте сайт по домену, затем откройте `https://ваш-домен/404.html` руками —
   должна открыться страница-заглушка.

FTP-доступ выдаётся в панели: *Доступы → FTP*. Хост обычно `ftp.<логин>.beget.tech`.
Вариант через Git (если нужен автодеплой): в панели *Сайты → Git* можно подключить
репозиторий и настроить выкладку в `public_html`.

### Форма заявки

По умолчанию форма работает в демо-режиме: валидирует поля и показывает сообщение,
но ничего не отправляет. Чтобы включить отправку:

1. В `php/send.php` замените `$MAIL_TO` (и при необходимости `$MAIL_FROM`)
   на рабочую почту домена.
2. В `index.html` у формы `<form class="form" id="lead-form" data-endpoint="">`
   укажите `data-endpoint="php/send.php"`.
3. Отправьте тестовую заявку с сайта после загрузки на хостинг.

Если письма не приходят, проверьте «Спам» и MX/SPF домена в панели Beget.
Альтернатива без почты — отправка в Telegram через Bot API: тот же `send.php`,
только вместо `mail()` запрос к `https://api.telegram.org/bot<token>/sendMessage`.

### HTTPS

`.htaccess` содержит закомментированное правило редиректа на HTTPS.
Включите «Let's Encrypt» в панели Beget, дождитесь выпуска сертификата и
раскомментируйте три строки в блоке `mod_rewrite`.

## Что где менять

- **Телефоны и имена** — `index.html`, блоки `.people` и ссылки `tel:` в шапке.
- **Цены и тарифы** — блок `.plans`, там же подписи «от 2 часов» и списки.
- **Тексты услуг** — карточки `.cards`.
- **Цвета и типографика** — переменные в начале `assets/css/style.css`
  (`--c-ink`, `--c-deep`, `--grad-brand`, `--fs-h1` и т.д.).
- **Фото на первом экране** — `assets/img/hero.jpg` (сейчас 474×438, взято из
  макета; для retina лучше заменить на кадр от 1000 px по ширине).

## Проверки перед публикацией

- телефоны кликабельны на мобильном (`tel:`);
- форма не отправляет пустые поля и не даёт отправить номер короче 10 цифр;
- на ширине 360–390 px нет горизонтальной прокрутки;
- `robots.txt` и `sitemap.xml` указывают на актуальный домен;
- в `index.html` обновлены `canonical`, `og:url`, `og:image` под реальный адрес.
